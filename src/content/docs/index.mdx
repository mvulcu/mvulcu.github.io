## Core Principles

<CardGrid>
  <Card title="Declarative IaC" icon="puzzle">
    100% of infrastructure is version-controlled via Terraform and Azure Bicep with strict state isolation and automated drift prevention.
  </Card>
  <Card title="Zero-Trust & Secret Hygiene" icon="star">
    Zero plain-text credentials in Git or Docker image layers; runtime injection via Google Secret Manager and managed identities.
  </Card>
  <Card title="Observability by Design" icon="information">
    Real-time health telemetry via `/api/health`, structured JSON logging, and InfluxDB time-series metrics.
  </Card>
  <Card title="FinOps Discipline" icon="approve-check">
    High availability and enterprise standards engineered with minimal cloud compute footprint and zero bill runaway risk.
  </Card>
</CardGrid>
