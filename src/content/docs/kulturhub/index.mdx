KulturHub is a **full-stack cloud-native platform** for managing cultural events, built with a DevOps-first approach.

## 🛠️ Technical Stack

#### Frontend
- **Framework:** Next.js 14 App Router
- **Language:** TypeScript
- **Styling:** Tailwind CSS & shadcn/ui

#### Backend & Data
- **API:** Next.js Server Actions & Route Handlers
- **Database:** MongoDB Atlas (M0 TLS connection)
- **Identity:** Stateless JWT in HTTP-Only Cookies

#### DevOps & Infrastructure
- **IaC:** Modular Azure Bicep
- **Compute:** Azure App Service (Linux Web App)
- **CI/CD:** GitHub Actions (Build, Test, Smoke Test)
- **Metrics:** Telegraf + InfluxDB OSS
